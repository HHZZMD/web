这是什么风格

它叫废土工业 / 战术 HUD 风：把"军事指挥终端 + 末世废土"当成界面语言。底色是接近黑的灰（`#0e0f12`），文字是暖白而非纯白，点缀色极少——红代表暴力/血、黄代表警戒、蓝代表沉寂/哀伤。它没有合成波的霓虹张扬，也没有 Y2K 的果冻光泽，靠低饱和灰度 + 斜切角 + 颗粒噪点 + 双语技术标签建立"近未来、硬朗、可信"的辨识度。本页所有元素都由同一组 CSS 变量驱动——右上角切换主点缀色，整页联动。

② 六大手法实验室

每个手法都能单独抽出来用，卡片里有可抄的 CSS 片段。

斜切角 Notch

CLIP-PATH

用 clip-path 切掉右上+左下，做出"箭头/指示"方向感。

.notch{clip-path:polygon( 0 0, calc(100% - var(--notch)) 0, 100% var(--notch), 100% 100%, var(--notch) 100%, 0 calc(100% - var(--notch)));}

颗粒 / 半调噪点

GRAIN
颗粒底纹

固定叠层：点阵半调 + SVG feTurbulence 微噪，overlay 混合，可一键关。

body::after{content:"";position:fixed;inset:0; background:url("data:image/svg+xml,...feTurbulence..."); opacity:.05;mix-blend-mode:overlay;pointer-events:none}

警戒条纹

45° 重复斜纹 = 工业警戒线，常用于标题底/边框强调。

.stripes{background:repeating-linear-gradient( 45deg, var(--accent) 0 12px, transparent 12px 24px)}

双语技术标签

REUNION
整合运动

大写拉丁 + 字距拉开的展示字，配小号中文，制造"情报终端"感。

.en{font-family:var(--font-display); font-weight:700;letter-spacing:.14em;text-transform:uppercase} .cn{font-family:var(--font-cn);letter-spacing:.3em;color:var(--ink-dim)}

失去同步 故障

SIGNAL LOST

hover 时马赛克条纹 + 抖动，致敬原站"失去同步"梗。

.sync:hover .bars{opacity:1; animation:jitter .18s infinite} @keyframes jitter{50%{transform:translate(2px,-1px)}}

灰度 + 点缀

大面积灰 + 零星红黄蓝，饱和度刻意压低才出"质感"。

/* 红=暴力 黄=警戒 蓝=沉寂；暖白#e9e6df非纯白 */ body{background:#0e0f12;color:#e9e6df} .accent{color:var(--accent)}
